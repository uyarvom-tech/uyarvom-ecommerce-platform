# Uyarvom E-commerce Platform

Modern e-commerce platform built with Next.js 16, TypeScript, and Prisma.

## Quick Start

```bash
npm install
cp .env.example .env.local
npx prisma migrate dev
npm run dev
```

Visit `http://localhost:3000`
