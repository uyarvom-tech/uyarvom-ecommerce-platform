# AI Image Generation Feature

## Overview
This feature uses Gemini AI to generate additional product images based on existing product images and descriptions. Each product can have up to 4 images with different purposes.

## Image Structure
- **Image 1**: Main product image (manually uploaded by admin)
- **Image 2**: Alternative view generated by AI (different angle/perspective)
- **Image 3**: Feature highlight 1 (lifestyle, context, or key feature showcase)
- **Image 4**: Feature highlight 2 (detail shot, material quality, or secondary feature)

## How It Works

### 1. Single Product Generation
- Navigate to: Admin → Catalog → Category → Subcategory → Product → Edit
- Click the **"Generate X Images with AI"** button in the top right
- The system will:
  1. Check how many images the product already has
  2. Generate the remaining images (up to 4 total)
  3. Use the existing image as reference
  4. Create prompts based on category, product name, and descriptions
  5. Generate images using Gemini AI

### 2. Bulk Subcategory Generation
- Navigate to: Admin → Catalog → Category → Subcategory
- Click the **"Fill All Images (X)"** button
  - The button shows how many products need images
  - The button is disabled if all products already have 4 images
- The system will:
  1. Find all products in the subcategory with less than 4 images
  2. Generate missing images for each product
  3. Process them with rate limiting to avoid API throttling

## Prompts

The prompts are stored in separate files for easy customization:

**Location**: `uyarvom-ecommerce-platform/lib/prompts/image-generation.ts`

### Editing Prompts

To customize how images are generated, edit the following functions:

```typescript
// Alternative View Prompt (Image 2)
export function generateAlternativeViewPrompt(context: ProductContext): string

// Feature Highlight 1 (Image 3)
export function generateFeatureHighlight1Prompt(context: ProductContext): string

// Feature Highlight 2 (Image 4)
export function generateFeatureHighlight2Prompt(context: ProductContext): string
```

Each prompt receives a context object containing:
- `category`: The product's category name
- `productName`: The product's name
- `longDescription`: Full product description
- `shortDescription`: Short product description
- `existingImageUrl`: URL of the first product image (for reference)

## API Endpoints

### Generate Images for Single Product
```
POST /api/admin/products/[id]/generate-images
```

**Response:**
```json
{
  "success": true,
  "message": "Generated 3 images",
  "generated": 3,
  "total": 4,
  "details": [...]
}
```

### Generate Images for All Products in Subcategory
```
POST /api/admin/categories/[categoryId]/[subCategoryId]/generate-all-images
```

**Response:**
```json
{
  "success": true,
  "message": "Processed 15 products",
  "processed": 15,
  "totalGenerated": 42,
  "results": [...]
}
```

## Configuration

### Environment Variables

Add to `.env.local`:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### Rate Limiting

The bulk generation includes a 500ms delay between products to avoid rate limits. Adjust in:
```typescript
// In generate-all-images/route.ts
await new Promise((resolve) => setTimeout(resolve, 500))
```

## Troubleshooting

### Button Not Showing
- Check that product has at least 1 existing image
- Verify product has less than 4 total images
- Ensure you're logged in as staff/admin

### Generation Fails
- Check GEMINI_API_KEY is set correctly
- Verify API quota/rate limits
- Check browser console and server logs for errors

### Images Not Appearing
- Currently, Gemini generates image descriptions (text)
- **TODO**: Integrate actual image generation API (Imagen, DALL-E, etc.)
- Generated images need to be uploaded to R2 and saved to database
