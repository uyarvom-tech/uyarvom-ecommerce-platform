# Maintenance Scripts

Scripts for database maintenance, backups, and data management.

## Available Scripts

- `backup-data.js` - Create database backups
- `restore-data.js` - Restore from backups
- `seed-reviews.js` - Add sample reviews
- `seed-variants.js` - Add product variants

## Usage

Run scripts from the project root:

```bash
node scripts/maintenance/backup-data.js
node scripts/maintenance/restore-data.js
```
